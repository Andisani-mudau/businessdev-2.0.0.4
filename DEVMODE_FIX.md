# Fixing Dev Mode Initialization Error

## Problem

The application fails to start on Render with this error:
```
Failed to determine project directory for dev mode. Directory '/app' does not look like a Maven or Gradle project. 
Ensure that you have run the prepare-frontend Maven goal, which generates 'flow-build-info.json', prior to deploying your application
```

This happens because:
1. Vaadin is trying to initialize dev mode even though production mode is enabled
2. The `flow-build-info.json` file is missing from the JAR
3. Without this file, Vaadin can't determine if it should use production or dev mode

## Root Cause

The `flow-build-info.json` file is generated by the `build-frontend` Maven goal during the build process. If this file is missing from the JAR, Vaadin assumes dev mode should be used and tries to initialize it, which fails in a production environment.

## Solution

### 1. Explicitly Disable Dev Mode

Added to `application-prod.properties`:
```properties
vaadin.devmode.enabled=false
```

### 2. Ensure Production Mode in Build

Updated `pom.xml` production profile to:
- Set `productionMode=true` in both `prepare-frontend` and `build-frontend` configurations
- Ensure Spring Boot plugin excludes devtools in production
- Configure proper execution phases for frontend build goals

### 3. Verify Build Process

The build must:
1. Run `prepare-frontend` in `generate-resources` phase
2. Run `build-frontend` in `prepare-package` phase (before JAR packaging)
3. Generate `META-INF/VAADIN/config/flow-build-info.json`
4. Include the file in the final JAR

## Verification

### Check Build Logs on Render

Look for:
```
[INFO] --- vaadin-maven-plugin:24.5.0:prepare-frontend
[INFO] --- vaadin-maven-plugin:24.5.0:build-frontend
[INFO] BUILD SUCCESS
```

### Verify JAR Contents

After build, the JAR should contain:
- `META-INF/VAADIN/config/flow-build-info.json`
- `META-INF/VAADIN/build/` directory with production bundle files

### Test Locally First

Before deploying to Render, test the build locally:
```bash
./mvnw clean package -Pproduction
java -jar target/businessdev-1.0-SNAPSHOT.jar --spring.profiles.active=prod
```

If it works locally but fails on Render:
1. Check Render build logs for frontend build errors
2. Verify Node.js is available (Render should provide it automatically)
3. Check if build times out (frontend build can take 5-10 minutes)
4. Verify memory is sufficient for the build

## Expected Behavior After Fix

- Build completes successfully with frontend production bundle
- `flow-build-info.json` is included in JAR
- Application starts in production mode
- No dev mode initialization attempts
- Fast page loads with optimized frontend

## If Issue Persists

1. **Check Render Build Logs**: Look for any errors during `build-frontend` goal
2. **Verify Node.js**: Ensure Node.js 18+ is available during build
3. **Increase Build Timeout**: Frontend build can take 5-10 minutes
4. **Check Memory**: Frontend build requires sufficient memory
5. **Verify Build Command**: Ensure `-Pproduction` profile is used
